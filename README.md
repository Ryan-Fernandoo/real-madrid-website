# Real Madrid – Website Profile

Website profil Real Madrid merupakan proyek personal yang dikembangkan menggunakan HTML, CSS, dan JavaScript. Proyek ini dibuat sebagai salah satu bentuk penerapan kemampuan dalam pengembangan website, dengan berfokus pada penyajian informasi, tampilan yang responsif, serta navigasi yang interaktif.

## Deskripsi Proyek

Proyek ini bertujuan untuk membangun sebuah website profil yang menyajikan informasi mengenai Real Madrid dalam tampilan yang terstruktur dan mudah diakses. Dalam proses pengembangannya, website dirancang agar dapat menyesuaikan tampilan pada berbagai ukuran perangkat, baik desktop maupun mobile.

## Teknologi yang Digunakan

- **HTML** – Menyusun struktur dan elemen halaman website.
- **CSS** – Mengatur tata letak, tampilan visual, dan responsivitas website.
- **JavaScript** – Mendukung fungsi dan interaksi pada website.

## Fitur dan Implementasi

- Penerapan desain responsif untuk tampilan desktop dan mobile.
- Penggunaan semantic HTML dalam penyusunan struktur halaman.
- Navigasi interaktif untuk memudahkan pengguna menjelajahi website.
- Pengelolaan aset gambar sebagai bagian dari elemen visual website.

## Tujuan dan Pembelajaran

Melalui proyek ini, saya mempelajari proses pengembangan website mulai dari penyusunan struktur halaman, pengaturan tampilan menggunakan CSS, hingga penerapan JavaScript untuk mendukung interaksi pengguna. Proyek ini juga menjadi kesempatan untuk memahami penerapan responsive design dan pengelolaan struktur file dalam sebuah pengembangan website.
